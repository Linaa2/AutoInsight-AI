# AutoInsight-AI

AutoInsight-AI is a proof-of-concept (POC) of an AI agent that automatically analyzes datasets (CSV/Excel), generates visualizations, answers natural language questions via Text-to-Code, and produces a comprehensive analysis report. The system is orchestrated by LangGraph, monitored by LangFuse, with contextual memory provided by ChromaDB.

## Project Structure
The project is structured into several key components:
- **Profiler Agent**: Responsible for analyzing the dataset and generating a structured profile that includes statistics, data quality issues, and other relevant information.
- **Analyst Agent**: Takes the profile generated by the Profiler Agent and produces actionable insights in a structured format.
- **Visualizer Agent**: Generates visualizations based on the insights and the dataset profile to help users better understand the data and the insights.
- **Reporter Agent**: Compiles the insights and visualizations into a comprehensive report that can be easily shared and understood by users.
- **UI**: A user interface built with Streamlit that allows users to upload datasets, view profiles, insights, and visualizations in an intuitive way.
- **Text-to-Code Agent**: An agent that generates executable code based on user queries and the dataset profile, allowing users to perform custom analyses or modify visualizations.
- **LangGraph Orchestrator**: Manages the workflow between the different agents based on user queries and interactions.

## Architecture Overview
1. **Data Ingestion**: Users upload datasets through the UI, which are then processed by the Profiler Agent to generate a structured profile.
2. **Insight Generation**: The Analyst Agent takes the profile and sample data to generate insights in a structured JSON format.
3. **Visualization**: The Visualizer Agent uses the insights and profile to create relevant charts and visualizations, which are rendered in the UI.
4. **Reporting**: The Reporter Agent compiles the insights and visualizations into a comprehensive report for the user.
5. **Orchestration**: The LangGraph Orchestrator manages the interactions between agents and ensures a smooth workflow based on user queries and actions.
6. **Monitoring and Memory**: LangFuse is used for monitoring agent interactions and performance, while ChromaDB serves as a memory layer for storing profiles, insights, critiques, and other relevant information for retrieval in future analyses.
7. **Text-to-Code Agent**: The Text-to-Code Agent answers user queries by generating executable code based on the insights and profiles.
8. **Evaluation**: An LLM-as-judge evaluates the quality of generated insights and visualizations, providing feedback for continuous improvement.
9. **RAG**: A Retrieval-Augmented Generation (RAG) component retrieves relevant past insights and critiques to inform current analysis and provide context to users.
10. **Adversarial Critic**: A Critic Agent evaluates the generated insights and visualizations, providing feedback to improve their quality and relevance.
11. **Uncertainty Estimation**: An Uncertainty Agent assesses the confidence of the generated insights and visualizations, providing users with information about potential limitations or uncertainties in the analysis.

## Technologies Used
- **LLM**: Ollama local models (one for pure text processing and another for code generation) for natural language processing and insight generation.
- **Monitoring**: LangFuse for tracking agent interactions and performance.
- **Memory**: ChromaDB for storing profiles, insights, critiques, and other relevant information for retrieval and context in future analyses.
- **Visualization**: Plotly for creating interactive charts and visualizations.
- **UI**: Streamlit for building the user interface.
- **Utilities**: Python libraries such as pandas, numpy, openpyxl for data manipulation and analysis.
- **Execution**: A sandboxed Python environment for safely executing generated code.
- **Orchestration**: LangGraph for managing the workflow between agents based on user queries and interactions.
- **Evaluation**: An LLM-as-judge for evaluating the quality of generated insights and visualizations based on criteria such as correctness, relevance, and clarity.
- **RAG**: A Retrieval-Augmented Generation component for retrieving relevant past insights and critiques to inform current analysis and provide context to users.

## Design Principles
- **Modularity**: Each agent has a clear responsibility, structured inputs/outputs, and no overlapping logic to ensure maintainability and scalability.
- **Structured Outputs**: Use of JSON for charts, Markdown for reports, and typed objects for pipeline state to ensure consistency and ease of integration between components.
- **Safe Execution**: Implementation of a restricted code execution environment to prevent security risks while allowing for dynamic code generation and execution based on user queries and insights.
- **User-Centric Design**: The UI is designed to be intuitive and responsive, with features that allow users to interact with insights and visualizations, provide feedback, and easily navigate through different sections of the application.

## Installation and Setup
1. Clone the repository:
    ```bash
    git clone https://github.com/Linaa2/AutoInsight-AI.git
    cd AutoInsight-AI
    ```
2. Install dependencies (`uv` should be installed globally):
    ```bash
    make install
    ```
3. Set up environment variables by copying `.env.example` to `.env` and filling in the required values:
    ```bash
    cp .env.example .env
    ```
4. Run the Streamlit application:
    ```bash
    make run
    ```
5. Access the application in your web browser at `http://localhost:8501`.
6. Upload a CSV or Excel file to start analyzing your dataset and generating insights and visualizations. You can also ask questions in natural language to get specific insights or generate custom visualizations based on the dataset profile.
